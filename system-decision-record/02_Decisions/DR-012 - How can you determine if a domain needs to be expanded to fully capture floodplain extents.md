## Description
Automate procedures for model domain creation will never work perfectly.  This may lead to situations where water pools on domain edges and the FIM underestimates flooding. 

This DR explores options for dynamically determining after a simulation whether water is pooling on an edge in a way that impacts FIM extents negatively.
